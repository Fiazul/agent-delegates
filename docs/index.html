agent-delegates

Run Codex, Antigravity, Grok Build, Claude Code, Cursor, and OpenCode workers in reusable terminal windows from your main coding agent.

npx --yes github:Fiazul/agent-delegates install

Durable global install:

npm install -g github:Fiazul/agent-delegates
GitHub repo README

How it works

  1. Write a brief describing the task, save it as BRIEF.md.
  2. Run agent-delegates run <vendor> <tier> BRIEF.md --cd repo.
  3. The worker runs in its own reusable terminal window, one per vendor/name.
  4. Collect last.md and exit from the job's output directory, or resume the same thread with a follow-up brief.

Features

Pace-based routing

Compares Claude weekly usage to elapsed time in the window. agent-delegates pick --json returns the vendor/tier/command to run.

run auto failover

Picks the first vendor with quota from a priority list; on quota exhaustion, hands off to the next vendor. Non-quota failures never hop.

Cross-vendor handoff

handoff <job-dir> <vendor> [tier] builds a continuation brief from a finished job's brief, failure reason, git status/diff, and last worker message.

Critical-work guard

Refuses small/standard models on production-shaped work. --critical or a routing.json guard.paths match requires a large tier; --allow-small overrides.

90-minute job timeout

Every run/resume job is killed after --timeout minutes (default 90) and classified "timed out"; exit code 124.

Login preflight

Codex, Grok, Cursor, and OpenCode get a cheap local auth check before a job is submitted, so it doesn't fail minutes later.

Quota status table

agent-delegates status shows CLI, remaining quota, and models for all six vendors.

Install wizard

Asks which CLI is your main orchestrator and which delegates to wire up, then checks/offers to install the missing vendor CLIs.

Cursor/Grok agent conflict detection

Both CLIs install a binary named agent. Install detects the PATH collision and offers to rename the duplicate aside.

Zero runtime deps, MIT

No runtime npm dependencies, no Python, no jq, no build step. MIT licensed.
