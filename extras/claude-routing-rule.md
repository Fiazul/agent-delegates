## Cross-vendor routing (Codex / Antigravity / Grok / Cursor / OpenCode)

- Before spawning workers, run `agent-delegates status` (or `npx github:Fiazul/agent-delegates status`). Quote its Claude week % and the chosen vendor's line in the report whenever an external worker is fired.
- If Claude week ≥ 40% and I did not name Opus/Fable for the task, route non-trivial work to external workers first: Antigravity (`delegate-antigravity`, free) → Codex (`delegate-codex`, paid quota) → Cursor (`delegate-cursor`) / OpenCode (`delegate-opencode`) → Grok (`delegate-grok`, only when not 402). Claude subagents stay for `opus5-reviewer` when asked, and as fallback when externals refuse/fail twice.
- Below 40%, Claude workers remain the default; externals when I ask ("summon codex", "use agy", "use cursor", "use opencode") or for a second-vendor opinion.
- External workers get the same brief discipline (constraints, acceptance, sole-executor preamble — the launchers prepend it), the same review gate, and the same artifact-state verification. Each external worker runs in its own terminal window (launcher does it); never ask the user to attach to tmux. Antigravity runs `--yolo` by default (authorised 2026-09-13); Codex stays sandboxed (`workspace-write`), never `--dangerously-bypass-approvals-and-sandbox`.
- Codex tiers: luna≈Haiku, terra≈Sonnet (default), sol≈Opus, astra≈Fable (allowed for Codex; hardest only). Antigravity: lite/flash(default)/pro + claude-sonnet/opus on Google quota. Cursor: auto(default)/composer. OpenCode: free(default)/go.
- `agent-delegates run auto BRIEF.md --cd DIR` is the mechanical form of this rule: it picks the first vendor with quota in the same agy→codex→grok→cursor→opencode→claude order (override with `--priority`) and, on quota exhaustion only, hands off to the next one automatically via `handoff` — no need to manually re-check `status` and re-launch by hand. Prefer it over the manual sequence above when you just want the brief to land somewhere with quota.
