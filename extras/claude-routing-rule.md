## Cross-vendor routing (Codex / Antigravity / Grok / Cursor / OpenCode)

- Hard cap: at most **3 workers running at once** (external + Claude subagents + reviewers combined), unless the user explicitly asks for more in that request. Count live workers before every spawn; if at 3, wait for one to finish (or `close` an idle one) and queue the next brief instead of fanning out.
- Before any spawn run `agent-delegates pick --json` and follow it; `--critical` for prod/servers/live data. `pick` decides — pace-based, configurable via `~/.config/delegates/routing.json` (see README.md "When does the orchestrator delegate? (routing policy)") — not a fixed 40% cutoff, and hands back the exact vendor/tier/command to use (or says stay in-house). `run auto BRIEF.md --cd DIR` is the fire-and-forget form of the same policy — it runs `pick`-equivalent logic itself and launches the job in one step, for when a single manual `pick` + `run` round trip isn't needed. Quote `pick`'s `route`/`reason` and the chosen vendor in the report whenever an external worker is fired.
- If `pick` says `route:"external"` and I did not name Opus/Fable for the task, run the `command` it gives (or route non-trivial work to external workers in the same order it's applying: Antigravity (`delegate-antigravity`, free) → Codex (`delegate-codex`, paid quota) → Grok (`delegate-grok`, only when not 402) → Cursor (`delegate-cursor`) / OpenCode (`delegate-opencode`)). Claude subagents stay for `opus5-reviewer` when asked, and as fallback when externals refuse/fail twice.
- When `pick` says `route:"claude"`, `"unknown"`, or `"none"`, stay in-house; externals only when I ask ("summon codex", "use agy", "use cursor", "use opencode") or for a second-vendor opinion.
- External workers get the same brief discipline (constraints, acceptance, sole-executor preamble — the launchers prepend it), the same review gate, and the same artifact-state verification — use skills/delegate-codex/brief-template.md; Goal, Scope out and Acceptance criteria are mandatory. Each external worker runs in its own terminal window (launcher does it); never ask the user to attach to tmux. Antigravity runs `--dangerously-skip-permissions` by default (headless `accept-edits` auto-denies every shell command; authorised 2026-09-13) — `--safe` opts back into accept-edits; Codex stays sandboxed (`workspace-write`), never `--dangerously-bypass-approvals-and-sandbox`.
- Codex tiers: luna≈Haiku, terra≈Sonnet (default), sol≈Opus, astra≈Fable (allowed for Codex; hardest only). Antigravity: lite/flash(default)/pro + claude-sonnet/opus on Google quota. Cursor: auto(default)/composer. OpenCode: free(default)/go.
- `agent-delegates run auto BRIEF.md --cd DIR` picks the first vendor with quota in the same agy→codex→grok→cursor→opencode→claude order (override with `--priority`) and, on quota exhaustion only, hands off to the next one automatically via `handoff` — no need to manually re-check `status`/`pick` and re-launch by hand. Prefer it over the manual `pick` + `run` sequence above when you just want the brief to land somewhere with quota in one step.
